# Welcome

Welcome to your project's documentation. Replace this page with an introduction to your project.

Add Markdown (`.md`) or MDX (`.mdx`) files under `website/docs/` to create more pages. The sidebar is generated automatically from this directory's files and folders.

Run `npm --prefix website start` from the repository root to preview your changes at [http://localhost:3000](http://localhost:3000). Edits reload automatically while the server is running.
